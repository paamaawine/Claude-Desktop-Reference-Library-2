# Verified Chart Standards

Charts should help users understand data quickly and accurately.

## Chart Selection

Choose the chart type based on the data.

Use:

-	Line charts for trends over time
-	Bar charts for comparisons between categories
-	Horizontal bar charts for ranked categories
-	Grouped bar charts for comparing multiple groups
-	Stacked bar charts for showing category composition
-	100% stacked bar charts for comparing proportions
-	Pie charts for simple proportions
-	Doughnut charts for simple proportions
-	Histograms for distributions
-	Frequency polygons for comparing distributions
-	Density plots for smooth distributions
-	Box plots for distributions, spread and outliers
-	Violin plots for distributions and density
-	Dot plots for small datasets and category comparisons
-	ECDF plots for cumulative distributions
-	Scatter plots for relationships between variables
-	Bubble charts for relationships involving three variables
-	Scatterplot matrices for relationships among several variables
-	Regression plots for relationships with fitted regression lines
-	Hexbin plots for dense scatter data
-	Error-bar charts for means and confidence intervals
-	Confidence-interval plots for comparing estimates
-	Forest plots for effect sizes and confidence intervals
-	Q–Q plots for checking normality
-	P–P plots for comparing probability distributions
-	Residual plots for regression diagnostics
-	Partial regression plots for individual predictors
-	Cook's distance plots for detecting influential observations
-	Heatmaps for patterns in matrices and correlations
-	Clustered heatmaps for grouped variables or observations
-	Correlograms for correlation matrices
-	Parallel coordinate plots for comparing multiple variables
-	Radar charts for comparing multiple dimensions
-	PCA biplots for principal component analysis
-	Loading plots for showing variable contributions
-	Factor-loading plots for exploratory factor analysis
-	Time-series charts for changes across time
-	Area charts for cumulative trends
-	Stacked area charts for changes in composition over time
-	Moving-average charts for smoothed time trends
-	Seasonal plots for recurring time patterns
-	Autocorrelation plots for time dependence
-	Partial autocorrelation plots for time-series analysis
-	Control charts for monitoring process changes
-	Likert charts for questionnaire responses
-	Diverging Likert charts for positive and negative responses
-	Grouped Likert charts for comparing survey groups
-	Frequency charts for response frequencies
-	Mosaic plots for relationships between categorical variables
-	Association plots for categorical relationships
-	Waterfall charts for sequential changes
-	Funnel charts for stages in a process
-	Pareto charts for identifying major contributing categories
-	Treemaps for hierarchical proportions
-	Sunburst charts for hierarchical data
-	Sankey diagrams for flows between categories
-	Network graphs for relationships between entities
-	Choropleth maps for regional comparisons
-	Bubble maps for location-based quantities
-	ROC curves for classification performance
-	Precision–Recall curves for classification performance
-	Kaplan–Meier curves for survival analysis
-	Survival plots for comparing survival groups
-	Calibration plots for predicted versus observed probabilities
-	Learning curves for model performance across training sizes
-	Feature-importance charts for machine-learning predictors
-	Confusion-matrix charts for classification results
-	Gain charts for classification performance
-	Lift charts for classification performance
-	Cluster plots for grouping observations
-	Dendrograms for hierarchical clustering
-	Discriminant plots for group separation
-	Canonical correlation plots for relationships between variable sets
-	Correspondence analysis plots for categorical associations
-	Bland–Altman plots for agreement between measurements
-	Profile plots for comparing group means
-	Interaction plots for examining interaction effects
-	Marginal-effects plots for showing predictor effects
-	Mediation diagrams for indirect relationships
-	Moderation plots for interaction effects
-	SEM path diagrams for structural equation models


Do not use a chart simply for decoration.

## Chart Labels

Charts should have clear:

- Titles
- Axis labels
- Legends where required
- Data labels where useful
- Units where applicable

## Accuracy

Charts must represent the underlying data correctly.

Do not:

- Distort the scale
- Hide important values
- Use misleading axes
- Remove relevant categories without explanation
