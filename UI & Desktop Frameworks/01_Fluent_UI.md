# Verified Fluent UI Standards

Fluent UI should be used to create clean, consistent and professional desktop interfaces.

## Design Principles

Use:

- Clear visual hierarchy
- Consistent spacing
- Simple navigation
- Consistent typography
- Clear actions
- Meaningful icons
- Appropriate feedback

Avoid unnecessary decoration.

## Navigation

Use a clear navigation structure.

Suitable patterns include:

- Sidebar navigation
- Top navigation
- Tab navigation
- Breadcrumbs where useful

Keep navigation consistent across the application.

## Buttons

Buttons should clearly describe their action.

Good examples:

- Save
- Update
- Delete
- Export
- Print
- Cancel

Avoid unclear labels such as:

- Click Here
- Submit
- Do It

Destructive actions should be visually distinct and require confirmation where appropriate.

## Forms

Forms should use:

- Clear labels
- Logical field order
- Consistent spacing
- Appropriate input controls
- Validation messages

Required fields should be clearly identified.

## Cards

Cards may be used to group related information.

Do not use excessive cards when a simple layout would be clearer.

## Tables

Tables should support:

- Sorting
- Searching
- Filtering
- Column resizing where appropriate
- Clear headers
- Suitable row spacing

Large datasets should not unnecessarily load every record into the UI.

## Feedback

Provide clear feedback after important actions.

Examples:

- Saved successfully
- Record updated
- Record deleted
- Export completed
- Import failed

## Responsive Design

The interface should remain usable when:

- The window is resized.
- The application is maximised.
- Different screen resolutions are used.
- High-DPI displays are used.

## Accessibility

Support:

- Keyboard navigation
- Clear focus states
- Readable text
- Adequate contrast
- Clear labels
- Tooltips where useful

Do not rely on colour alone to communicate important information.

## Fluent UI Checklist

- [ ] Clear visual hierarchy
- [ ] Consistent navigation
- [ ] Consistent spacing
- [ ] Clear button labels
- [ ] Forms are easy to use
- [ ] Tables support useful operations
- [ ] User feedback is provided
- [ ] Responsive layouts are used
- [ ] Accessibility is considered
