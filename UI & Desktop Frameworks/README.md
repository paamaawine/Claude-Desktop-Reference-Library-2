## Primary Framework

For new professional Python desktop applications that require a full-featured Qt interface, PySide6 should normally be considered first.

## General Rule

Claude should:

- Follow the verified UI standards.
- Keep UI code separate from business logic.
- Use responsive layouts.
- Validate user input.
- Keep the interface responsive.
- Handle loading, empty and error states.
- Consider accessibility.
- Use consistent themes and icons.
- Avoid unnecessary animation.
- Avoid mixing UI frameworks without a clear reason.

Existing project architecture and requirements should always be considered before introducing a new library or framework.
