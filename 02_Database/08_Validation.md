# Verified Data Validation Standards

Applications should validate user input before saving or processing data.

## Validation Types

Use appropriate validation for:

- Required fields
- Text
- Numbers
- Dates
- Email addresses
- Phone numbers
- Passwords
- File uploads
- Selection fields
- Database records

## Required Fields

Required fields should not accept empty values.

Example:

```text
Name:        Required
Email:       Required
Phone:       Required
Address:     Optional
