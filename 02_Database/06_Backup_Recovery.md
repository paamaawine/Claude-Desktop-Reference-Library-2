# Verified Backup and Recovery Standards

Database backup and recovery should protect important information and provide a safe way to restore the application after data loss or database failure.

## Backup Types

Depending on the application, support:

- Manual Backup
- Automatic Backup
- Scheduled Backup
- Full Backup
- Incremental Backup where required

For a simple desktop application, a reliable full backup may be sufficient.

## Backup Database
