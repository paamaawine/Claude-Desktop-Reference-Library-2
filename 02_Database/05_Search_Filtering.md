# Verified Search and Filtering Standards

Search and filtering should help users find records quickly without loading unnecessary data.

## Search

Search should support the fields users are most likely to use.

Examples include:

- Name
- Registration number
- Email
- Phone number
- Status
- Date
- Category

## Partial Search

Where useful, allow users to search using part of a value.

Example:
