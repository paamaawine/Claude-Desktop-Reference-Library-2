# Verified SQLAlchemy Standards

SQLAlchemy provides a Python interface for working with relational databases and can be used to separate database operations from application logic.

## Purpose

Use SQLAlchemy where the application benefits from:

- ORM-based database access
- Database abstraction
- Structured models
- Relationships
- Transactions
- Migration support
- Switching between supported database engines
